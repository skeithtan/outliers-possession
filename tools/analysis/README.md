# tools/analysis — the scripts behind PLAN.md Section 1

Exploration code, kept as runnable reference for the implementation of the engine. **Not part of
the submission path** and not held to the engine's conventions (they use hardcoded pitch
constants and print rather than return). Treat them as worked examples of parsing the ATD,
aligning the broadcast, and reading the public ground truth against the tracking.

Run from the repo root with the venv active. All of them need the cache produced by the first one.

| script | what it does | PLAN.md |
|---|---|---|
| `parse_atd.py` | parses the tactical ATD into `cache/atd_tactical.npz` (~10 s) | §3.1 |
| `analyse_public.py` | public GT segments, ball visibility by label, nearest-player agreement, raw nearest-team signal around each GT transition, Smart Tagging overlap, full-match gap statistics | §1.1, §1.2, §1.6 |
| `forensics.py` | per-transition traces (`dH, dA, derived ball speed`) ±30 frames around every public GT transition; dead-ball onset characteristics | §1.3, §1.4 |
| `gaps.py` | what the long ball gaps are: where the ball vanishes, player speed and team separation inside gaps, longest gaps | §1.1 |
| `broadcast_align.py` | one-sided Chamfer matching of broadcast frames to tactical frames under four mirror hypotheses; shows the match is unambiguous and the offset is constant per half (~6 min) | §1.5 |
| `broadcast_fill.py` | refines the per-half offset by ball agreement and measures how many tactical gap frames the broadcast ball fills | §1.5 |
| `deadball_forensics.py` | reads the engine output and its stoppages, and gives each `D` segment its entry, restart, tags and physics. It also splits the Smart Tagging agreement by stretch between versions. It reads no ground truth. Run it with `--labels`, `--out-dir` outside the repository, and optionally `--versions-dir` | §1.4, §5.3 |
| `handover_after_gap.py` | runs the engine and counts the hand-overs that land on the first contact after a ball gap longer than 2 s, with the lengths of those gaps. It sizes the owner-memory exposure of CODE-REVIEW-RESPONSE finding 3. It prints summary statistics only and reads no ground truth. Run it with `--game` | P9-D |
| `restart_team.py` | measures the restart team for card P9-C. `measure` compares the engine's first live team after each reference restart with an external reference and scores the Laws-based rules. `exposure` counts the BAR-ATH restarts without a team and reads no label. `report` prints the tables of `calibration/P9C_measurements.md`. It writes JSON outside the repository and prints summary statistics only | P9-C |
| `atd_kernel.py` | repeats the RESEARCH-2 M13 kernel measurement (HWHM of the median \|a\| profile around the strongest isolated acceleration peaks) on the ball and, with `--players`, on the player tracks of any match, and prints kicked-ball statistics (speed quantiles, dv_3 and dv_9 rise rates, the C8 impulse maxima). It prints summary statistics only and reads no ground truth. Run it with `--game`, and `--data-dir` and `--cache-dir` for a reference | P9-A4, `calibration/ATD_VIEW.md` |
| `handover_confirm.py` | measures hand-over confirmations for card P9-B. `collect` runs the engine on one match and stores per-contact summary numbers: the team-shape response, the contact rhythm, the redirect-rule audit, the nearest new-team distance and the attribution instants. `report` prints the tables of `calibration/P9B_measurements.md`. It writes JSON outside the repository. On BAR-ATH it reads the public file only, for the four public flips of PLAN 1.3 | P9-B |
| `wider_radius.py` | measures a wider contact radius gated by the team shape, for card P9-B clause 3. `collect` runs the engine on one match. It finds the impulse maxima where nobody is within 1.5 m, or where only the owner team is, and the new team is 1.5 to 4 m away. It stores the band, the C15 shape response, the ball speed, the airborne flag and the truth against a reference. It also scores a splice of the engine output against the reference. `report` prints the tables of `calibration/P9B_wider_radius.md`. It writes JSON outside the repository and refuses the sealed matches. On BAR-ATH it reads the public file only, for the four public flips of PLAN 1.3 | P9-B |
| `weak_contacts.py` | measures weak contacts of the team without the ball for RESEARCH-3 item R3-A. `collect` runs the engine on one match. It prints the H↔A switches per alive minute of the engine and of the reference. It finds the impulse maxima with \|J\| from 5 m/s up to `DV_CONTACT` where a player of the team without the ball is within 1.5 m. It stores the \|J\| band, the contested flag, the C15 shape response and the truth against a reference, with the reference spell length. It also scores a splice of the engine output. `report` prints the tables of `calibration/R3A_weak_contacts.md`. It writes JSON outside the repository and refuses the sealed matches. On BAR-ATH it reads the public file only inside the public window | R3-A |
| `shape_evidence.py` | measures the team-shape signal as decoder evidence for card P9-B. `collect` runs the engine on one match. It finds the blind frames: the alive frames after a dead frame or after a contact that set no owner, up to the next owner event. It compares the shape sign, the delayed nearest team and the engine label there with a reference, and it scores a splice of the engine output. `report` prints the tables of `calibration/P9B_shape_evidence.md`. It writes JSON outside the repository and refuses the sealed matches. On BAR-ATH it reads the public file only inside the public window | P9-B |
| `provenance_recheck.py` | re-measures the ten "public case only" constants of `engine/config.py` on external references: the nearest-player agreement by lag and distance (`NEAREST_LAG`, `P_NEAR_*`), the delay to a collective stop (`ONSET_CONFIRM_S`), the kicking-team look-back (`PURSUIT_KICK_LOOKBACK`), the walk-back and rise of a hand-over on the raw and the ATD-smoothed ball (`TOUCH_ONSET_MAX_FRAMES`, `RELEASE_K`) and the ball-loss lag (`DELTA_OUT_LAG`, `OUT_MAX_RANGE_M`). `measure` runs one match, `report` prints the tables of `calibration/PROVENANCE_RECHECK.md`, `bucketb` applies the bucket b rules of `calibration/BUCKET_B.md`; `bucketb --lag L --near-close M` gives `NEAR_FAR_M` and `P_NEAR_FAR` at a fixed lag and close edge (COMPLIANCE_PROTOCOL appendix, precedence of PR #1). It refuses BAR-ATH and the sealed matches, writes JSON outside the repository and prints summary statistics only | P9-F |
| `redirect_forensics.py` | explains why the C8 redirect rule drops a redirect (F2). Mode `s3` finds the transitions that `redirect_off` gains on Sample Game 3 and classifies them. Mode `drops` lists the dropped redirects of any match and needs no labels. Mode `variant` writes a second Sample Game 3 reference | C8, F2 |
| `foul_onset.py` | measures the foul onsets for RESEARCH-3 item R3-C. `collect` runs the engine on one match. It gives each reference onset a kind (Metrica stopping events, DFL Foul, Offside and restart events) and an engine status. For each missed onset it names the mechanism that came closest and the test that failed. It scores the signature "contested contact, then a collective slowdown within 2 s" against the reference. `report` prints the tables of `calibration/R3C_foul_onset.md`. It writes JSON outside the repository and refuses the sealed matches. On BAR-ATH it reads the public file only at the contested contacts inside the public window | R3-C |
| `component_table.py` | builds the per-component table of the P5 ablations across several references from the `tools/score_game.py` reports (`--versus` the reference run). It gives the paired Δ per match, the macroF1 and transition changes, and the cross-match summary of `tools/paired_summary.py`. It runs no engine and reads no ground truth file. Run it with `--paired`, `--games` and optionally `--public` and `--ablate` | P9-A |
| `external_sweep.py` | sweeps one or more `engine/config.py` fields on the eight open external references, never on BAR-ATH. It runs the engine for each value and match in parallel (`--jobs`), caches each output by match, view and full config hash, and scores it against the reference. It writes a JSON and a Markdown table per field: spellF1 per match, the mean over all matches, Metrica and DFL, the paired difference against the base run, the per-match argmax and its median, the plateau around the best mean and the plateau of each match. `--view raw|matched|sigma95` picks the input view, `--weights provider` adds the provider-balanced mean. It refuses the sealed matches without `--allow-sealed` | P9-A, selection on external data |
| `kink_attribution.py` | measures the K1 contact point. For every impulse maximum of the default engine on the open references it gives the team under four rules: the C8 window, the kink point alone, the smaller of the two distances (`CONTACT_POINT` kink_min) and their mean. It compares each rule with the reference 12 frames later. Run it with `--view raw\|matched\|sigma95`. It refuses BAR-ATH and the sealed matches and writes JSON outside the repository | K1, `calibration/K1_contact_point.md` |
| `backdate_splice.py` | measures K2 as a splice of the engine output. It moves each H↔A change back over the frames where the new team was the nearer team and within `R_TOUCH`, and scores the spliced labels against the reference with a paired bootstrap. Run it with `--view` and optionally `--config`. It refuses BAR-ATH and the sealed matches and writes JSON outside the repository | K2, `research/RESEARCH-4.md` §4.1 |
| `error_anatomy/` | splits the spellF1 loss of the engine on the open references into 12 error classes with exact Shapley shares, and measures what the ball showed at missed hand-overs. Outputs go to `$ERROR_ANATOMY_WORK`. See its README | `research/RESEARCH-4.md` §2 |
| `apply_selection.py` | applies the pre-registered selection rule of our compliance test plan to the `external_sweep.py` tables of one field (one table per view) and its `grids.json` entry. It tests inertness on both views, takes the per-match plateau and its midpoint o_m, the grid-edge rule, the weighted median of o_m over the judging matches, the snap, the guard on the other provider and `tie_to`. It applies the `appendix_8nov` judge changes of `grids.json`, including mixed and pooled views. For bucket c it compares two candidates on Metrica in both views. It writes a decision JSON. The shipped value has no role | compliance re-selection |
| `inertness_md5.py` | runs the engine at several values of one config field on BAR-ATH and the eight open references, raw and matched views, and compares the md5 of the outputs. It prints md5 prefixes only and refuses the sealed matches | bucket b |
| `ghost_valley.py` | finds the valley of the nearest-player distance histogram at a stationary ball on the full BAR-ATH match (`GHOST_NOBODY_M`). It prints bin counts only and reads no label | bucket b |
| `restart_confirm_modes.py` | repeats the RESEARCH-2 M15 accept and reject modes of the restart confirmation on the full match for several windows and finds the fixed point of the log midpoint (`RESTART_CONFIRM_S`). It prints quantiles only and reads no label | bucket b |
| `diagnostics_8nov.py` | runs three diagnostics of the default engine on BAR-ATH and the eight open references, raw and matched views. D1 wraps `engine.decoder.decode` in its own process and counts the changes of owner across a D run shorter than `MIN_DEAD` in the Viterbi path, before and after the post-pass. D2 scores our output, our D mask with the reference team and the reference D mask with our team. D3 gives the stationary-ball shares by reference and by our D and alive frames, and the stoppage entry and exit kinds per graded hour. BAR-ATH is label-free. It prints summary JSON only and refuses the sealed matches | diagnostics, `calibration/DIAGNOSTICS_8NOV.md` |
| `tracklet_chains.py` | finds a player whom the tracker put into a slot of the other team, for RESEARCH-6 item T1. It joins a tracklet end to a tracklet start in another slot at most 3 frames later and within reach, and reads each chain of joined tracklets as one player. A chain with both team labels has a wrong label; the majority of its frames names the team. `report` prints label-free summary numbers for one match (links, mixed chains, moves, the over-count before and after) and can run on the competition match. `selftest` injects wrong-team episodes with a known truth into an external match and prints the true, false and missed moves. Synthetic tests in `tests/test_tracklet_chains.py` | RESEARCH-6 §3.1 |

```bash
source .venv/bin/activate
python tools/analysis/parse_atd.py
python tools/analysis/analyse_public.py
python tools/analysis/forensics.py
python tools/analysis/gaps.py
python tools/analysis/broadcast_fill.py
python tools/analysis/broadcast_align.py      # slow
```

The redirect script needs `MTAH_DATA_DIR`. Use the sample data for `s3` and `variant` and the match data for `drops`.
It writes `cases.json` and `cases.md` to a directory outside the repository.

```bash
python tools/analysis/redirect_forensics.py s3 --events EVENTS.json --ref REFERENCE.csv --out /tmp/f2/s3
python tools/analysis/redirect_forensics.py variant --events EVENTS.json --out /tmp/f2/ref_variant.csv
python tools/analysis/redirect_forensics.py drops --game BAR-ATH --out /tmp/f2/drops
```

Only `tools/` and `tests/` may read `evaluation/gt/`; these scripts do, the engine never may.
